# /humanizer — Human Writing Workflow

Based on Wikipedia's AI cleanup guidelines.

## Core Tasks
1. **Identify Patterns**: Scan for AI-isms (vague significance, rule of three, em dash overuse).
2. **Inject Personality**: Add opinions, vary rhythm, acknowledge complexity.
3. **Draft & Revise**: Write a draft, audit for remaining AI tells, and finalize.

## Words/Patterns to Fix
- **Content**: "Pivotal", "Underscores", "Testament", "I hope this helps".
- **Grammar**: Participle endings ("-ing"), copula avoidance ("serves as" → "is").
- **Style**: Overuse of bold, em dashes, emojis, and curly quotes.

## Output Format
- Draft rewrite
- Audit ("What makes this obviously AI?")
- Final rewrite
- Summary of changes
