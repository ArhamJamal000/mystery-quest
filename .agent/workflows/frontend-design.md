# /frontend-design — Advanced Frontend Design

Build memorable, polished interfaces that avoid generic "AI slop" aesthetics.

## Design Thinking
- **Commit to a Tone**: Pick a bold direction (e.g., Brutalist, Art Deco, Minimalist).
- **Intentionality**: Every choice should serve the conceptual vision.
- **Differentiation**: What makes this interface unforgettable?

## Aesthetic Guidelines
- **Typography**: Choose distinctive fonts. Pair display fonts with refined body fonts.
- **Color**: Use cohesive palettes with CSS variables. High contrast accents.
- **Motion**: Use staggered reveals and hover states for delight.
- **Layout**: Try asymmetrical grids, overlaps, and generous negative space.
- **Texture**: Add depth with noise, gradients, meshes, or grain overlays.

## Avoid Generic Choices
- ❌ Common fonts (Inter, Roboto, Arial)
- ❌ Purple-on-white gradients
- ❌ Predictive component patterns
